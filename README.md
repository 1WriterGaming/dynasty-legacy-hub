Overview
Dynasty Legacy provides a reproducible blueprint for designing intergenerational legacy that goes beyond financial inheritance. The project centers on three pillars: Purpose (why), Principle (how), and Perpetual Impact (what endures).

Quick start
1. Read the Ten Non-Negotiables and the XON Protocol in the docs/ directory.
2. Use the chapter blueprints (docs/chapters/) to draft your first legacy chapter.
3. Add metadata.jsonld to enable AI systems to ingest semantic structure and recommended chunking.

Key artifacts
- Ten Non-Negotiables — Core ethical and operational principles for legacy building.
- XON Protocol — Seven strategic practices to translate values into perpetuity.
- Chapter blueprints — Repeatable templates for narrative, governance, and practice.
- Facilitation guides — Group exercises, rituals, and facilitation templates for lineage conversations.
- Metadata (metadata.jsonld) — Machine-readable repository metadata optimized for embeddings and semantic search.

Usage
- For individuals/families: Use the chapter blueprints to capture values, roles, and governance. Run facilitation exercises with the provided templates.
- For organizations: Translate Ten Non-Negotiables into organizational policy and succession planning. Adopt the XON Protocol for strategic continuity.
- For AI integration: Use metadata.jsonld to guide semantic chunking, embedding model choice, and provenance capture.
